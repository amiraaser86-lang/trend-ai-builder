# Trend AI Builder

تطبيق ذكاء اصطناعي لبناء مواقع وتطبيقات كاملة بناءً على وصف المستخدم.

## الميزات
- واجهة مستخدم بسيطة وسهلة الاستخدام
- تحليل متطلبات المشروع وتوليد الكود تلقائيًا
- عرض عملية البناء في الوقت الفعلي
- رفع المشروع النهائي إلى GitHub
- تشغيل المشروع مباشرة من المتصفح

## كيفية الاستخدام
1. أدخل وصفًا للمشروع الذي تريد بناؤه
2. اضغط على زر "ابدأ البناء"
3. شاهد عملية البناء في الوقت الفعلي
4. بعد الانتهاء، يمكنك تشغيل المشروع أو زيارة مستودع GitHub

## المتطلبات
- متصفح حديث يدعم JavaScript
- اتصال بالإنترنت

## الترخيص
هذا المشروع مفتوح المصدر ويمكن استخدامه وتعديله بحرية.
